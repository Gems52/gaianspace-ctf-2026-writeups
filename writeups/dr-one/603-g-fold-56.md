# 603 · g-fold-56

> **Category:** Guidance / Math · **Points:** 199 · **Track:** [DR-ONE](README.md)

## Challenge

DR-ONE's guidance computer runs a g-FOLD-style powered-descent solution. The recovered thrust-acceleration plan (`descent_profile.csv`) and the release state and constants (`gfold_notes.md`) must be integrated forward under local (Mars) gravity to find exactly where the vehicle touches down in the `(x, y)` plane.

## Approach

This is a pure numerical-integration task. The notes deliberately remove any ambiguity about integration order, so any faithful implementation converges on the same landing site.

| Parameter | Value |
|---|---|
| Release position | `(2000.0, -500.0, 1500.0)` m |
| Release velocity | `(-40.0, 10.0, -60.0)` m/s |
| Mars surface gravity | `g = 3.711 m/s²`, acting along `-z` |
| Time step | `dt = 0.1 s` (matches the CSV sampling rate) |

For every row `(thr_ax, thr_ay, thr_az)` of the CSV:

1. total acceleration = thrust + gravity
2. update the velocity first: `v += a * dt`
3. then update the position: `p += v * dt` (semi-implicit Euler)
4. stop the first time `p.z <= 0`

### Key findings

- 203 rows of thrust samples are consumed before the vehicle reaches the ground, at `t ≈ 20.2 s`, right at the last row of the provided profile.
- Touchdown position before rounding: `x ≈ 1374.35 m`, `y ≈ -359.12 m` (`z ≈ -2.9 m`, just past the ground plane on the last step).
- Rounded to the nearest 10 m as required by the flag format: `x = 1370`, `y = -360`.

## Solution

```python
import csv

rows = list(csv.DictReader(open("descent_profile.csv")))
g, dt = 3.711, 0.1
p = [2000.0, -500.0, 1500.0]
v = [-40.0, 10.0, -60.0]

for r in rows:
    a = (float(r["thr_ax"]), float(r["thr_ay"]), float(r["thr_az"]) - g)
    v = [v[k] + a[k] * dt for k in range(3)]
    p = [p[k] + v[k] * dt for k in range(3)]
    if p[2] <= 0:
        break

x, y = round(p[0], -1), round(p[1], -1)
print(f"GAIANSPACE{{LZ_{int(x)}_{int(y)}}}")
```
